🖼 Scene Builder

A Canva-style editor for stream scenes - shapes, text, images, video, frames for webcams and game captures, widgets - published to OBS as one locked scene.

  • Frames with masks, borders, background removal (chroma / NVIDIA / transparent)
  • Widgets: Now Playing, chat, alerts, game cover, goals, counters, leaderboards, polls, visualizer, emote wall
  • Socials element with real platform logos, rotating / bar / stacked layouts
  • Text fills: solid, gradient, image, patterns
  • Re-publishes by itself when captures move; helper scenes stay hidden
