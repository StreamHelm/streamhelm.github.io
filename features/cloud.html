☁ StreamHelm Cloud + SQLite storage

PepeBot on an always-on server (a $4-6 VPS or a Raspberry Pi) while your PC is off - one shared memory, taking turns so only one PepeBot answers.

  • Set it up for me: paste a Hetzner / DigitalOcean / Vultr / Akamai (Linode) / UpCloud / Scaleway API token, pick the memory size and a location - StreamHelm buys the server, installs it and sends PepeBot over
  • Or one install command for any Ubuntu/Debian server or a 64-bit Raspberry Pi
  • Covers Twitch chat and the Discord bot while the PC is off, or keeps the Discord bot there all the time
  • Memory syncs both ways every few seconds; everything between PC and server is signed + encrypted
  • JSON files or one SQLite database for PepeBot's memory - a switch with an automatic, checked transfer (and back)
