v4.3.0 2026-10-29

v4.2.0 2026-10-28

  • SH.Voice - Skyrim NPCs are now their own plugin with their own page: a curated setup checklist per game that ticks itself off, the on/off and mode, NPCs & memory, Voices, Conversation and Live tabs. Plugins can be switched off in Settings → Plugins
  • Playthroughs: the character you play is a persona of its own, separate from you as the streamer - one per save (Pepe1, Pepe2…), picked automatically when the game starts a conversation. Each has its own NPC memories, relationships, directions, prompts and reply length; NPCs hear the persona; "Update from what NPCs know" rewrites it and it learns new facts after every talk; copy a build to start a new run or export / import it
  • Relationships read as sentences - "Luna is Child of 🎮 Pepe", "Friends with Lydia", "Married to…" - with as many as you like per character, a person dropdown that includes your character in each playthrough, more types (adversary, enemy, sworn enemy, nemesis, frenemy, crush, ex, mentor, protector, debtor and more) and an editable "of / with / to" per type; the AI that sums up each conversation now adds, changes and ends them as the story goes
  • xVASynth: every downloaded xVASynth voice (Skyrim's own voice actors and more) is in every StreamHelm voice menu; SH.Voice starts xVASynth's server when needed and background NPCs can use the model for their voice type; its FaceFXWrapper can do lip sync
  • Making sure NPCs really speak: the Live tab lists every line written into the game (voice folder, length, sample rate, lip sync) and says why when one wasn't; the old lip file is kept when no new one is made; optional resampling
  • Add a game: the AI drafts a setup menu for any game (how it connects, steps with links and folder pickers, prompts), you edit and save it - Skyrim is built in
  • The SH.Voice Skyrim mod: StreamHelm makes its own game mod (built on an MIT-licensed spell mod, compiled with an open-source Papyrus compiler - no Creation Kit) and hands it to your mod manager: save the zip for Vortex / MO2 or copy it into a folder. It reuses the SKSE plugins from your install, and installing it brings your existing prompts, settings and NPC memories over
  • In game: G talks to the NPC you look at; Y on one NPC and Y on another makes them talk to each other without you; both keys change in MCM → SH.Voice. "StreamHelm picks who talks" (on by default) chooses radiant and walk-up conversations from each character's chattiness and who they like or avoid talking to, and plays pairs you queue on the new Who talks tab - with an optional topic
  • The newer game protocol (one voice folder with two alternating line files, actions with arguments, microphone and push-to-talk through StreamHelm's speech-to-text); lines are written in place so Vortex's hard links keep working
  • Cloud: three more budget providers (Akamai / Linode, UpCloud, Scaleway), a memory picker before the location (1 GB recommended, pick more) and a live view of the server (CPU, memory, requests)
  • AI spend: how to turn on live balance tracking with an admin key is spelled out on each provider card

v4.1.0 2026-10-28

  • Always-on captions for deaf and hard-of-hearing viewers: everything you say, captioned live by Windows' own offline speech recognizer - no AI, no cost, nothing leaves the PC; they pause while an AI voice talks or listens and the AI's own text is captioned instead
  • 7 more caption looks: large + high contrast, classic closed captions, cinema bar, streaming service, lower third, neon, terminal - plus readable fonts (Atkinson Hyperlegible, Lexend, Roboto Mono)
  • Skyrim: StreamHelm can now answer the Skyrim mod itself - no extra program needed; it finds the mod's folders, notices when Skyrim starts, writes your StreamHelm voices (and lip sync with FaceFXWrapper) straight into the game, uses your prompts, captions + cast overlay, listens to your mic, and remembers each conversation
  • One character per NPC: an NPC with several game references (re-spawned followers, other saves) is one character with one memory; guards, soldiers and bandits stay separate people; flip any name either way
  • Relationship dynamics: spouse, partner, polycule, parent / child, sibling, pet / owner, rival, mentor and more - each says what it means and how it changes the way characters talk; edit them, make your own, import / export, groups (polycule, harem, family, crew), and relationships that form on their own after talks, scenes and Skyrim conversations (suggested or automatic)

v4.0.0 2026-10-28

  • Storage: PepeBot's memory can live in one SQLite database instead of thousands of JSON files - a switch on the new Cloud & Storage page with Test the switch, an automatic backup, a checked transfer, and the same switch back; older versions of every document are kept and every change is logged
  • StreamHelm Cloud: PepeBot on an always-on server - set it up for me (Hetzner, DigitalOcean or Vultr API token → server bought, installed, HTTPS, app + keys + memory sent), one install command for any server, or a Raspberry Pi at home
  • The PC and the server take turns: the server covers Twitch chat and the Discord bot while the PC is off (or keeps Discord all the time); memory syncs both ways; the server gets its own Twitch logins; updates itself when StreamHelm updates
  • Everything between PC and server is signed and encrypted with a key only those two have; keys on the server are encrypted at rest
  • This PC: choose the local server port and let other devices on your network reach it (two-PC setups, overlays on a gaming PC)
  • Setup guides with Assisted / Manual tabs, a Documentation section on the Launchpad, and Cloud & Storage status on the Dashboard and Connections
