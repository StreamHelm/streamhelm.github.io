OpenAI

Your own app: available

What StreamHelm uses it for

  • PepeBot's replies and memory updates
  • Clip titles / captions, clip watching (frames + audio, optional), captions from speech, trend lookups
  • Feature / quick-action generator

Permissions requested

  • API key

Data

Text prompts (chat context, clip details) and - only when switched on - clip frames and audio are sent to OpenAI for processing. The key is stored encrypted.

How to connect

  • Your own developer app - Your own developer app - you create a free app on the platform and paste its keys into StreamHelm's encrypted Key Vault. Works today; the app walks you through it step by step.

Setup in short: OpenAI API key with billing; a monthly budget can be set in the app

Remove access

  • https://platform.openai.com/api-keys
  • In StreamHelm: disconnect the account (deletes the stored token).
