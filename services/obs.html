OBS Studio

runs on your PC

What StreamHelm uses it for

  • Scenes, sources, audio, streaming / recording, screenshots and the virtual camera via obs-websocket on the same PC

Permissions requested

  • obs-websocket password

Data

Nothing leaves the PC.

Setup

Enable the WebSocket server in OBS (Tools → WebSocket Server Settings)

Remove access

  • Tools → WebSocket Server Settings in OBS
  • In StreamHelm: disconnect the account (deletes the stored token).
