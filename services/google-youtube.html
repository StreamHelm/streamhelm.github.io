YouTube (Google)

Your own app: availableStreamHelm shared app: planned

What StreamHelm uses it for

  • Upload the clips you choose as YouTube Shorts / videos
  • Show which channel is connected (name, handle, avatar)

Permissions requested

  • https://www.googleapis.com/auth/youtube.upload
  • https://www.googleapis.com/auth/youtube.readonly

Data

The sign-in token and the channel's name / handle / avatar / ID, stored encrypted on the user's PC only. No other YouTube or Google data is read.

How to connect

  • Your own developer app - Your own developer app - you create a free app on the platform and paste its keys into StreamHelm's encrypted Key Vault. Works today; the app walks you through it step by step.
  • StreamHelm's shared app - PepeBot's shared app - connect in one click with the app the StreamHelm project runs. Planned: being set up and (where needed) reviewed by the platform.

Setup in short: Google Cloud project with the YouTube Data API v3 · Google Auth Platform: External audience, Branding (home page, privacy policy, terms, authorized domain), Published · Desktop OAuth client → Client ID + secret into the Key Vault · Uploads are private until the project passes the YouTube API audit

Remove access

  • https://myaccount.google.com/permissions
  • Google account → Security → Third-party access
  • In StreamHelm: disconnect the account (deletes the stored token).

StreamHelm's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
