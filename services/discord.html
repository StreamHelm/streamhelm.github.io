Discord

Your own app: availableStreamHelm shared app: possible later

What StreamHelm uses it for

  • Run PepeBot as a Discord bot (chat, moderation, alerts, events)
  • Voice overlay: who is speaking in the streamer's voice channel

Permissions requested

  • Bot with Server Members + Message Content intents
  • rpc / rpc.voice.read for the local voice overlay

Data

Bot token (encrypted) and per-member memory on the streamer's PC.

How to connect

  • Your own developer app - Your own developer app - you create a free app on the platform and paste its keys into StreamHelm's encrypted Key Vault. Works today; the app walks you through it step by step.
  • StreamHelm's shared app - PepeBot's shared app - connect in one click with the app the StreamHelm project runs. Planned: being set up and (where needed) reviewed by the platform.

Setup in short: Discord application + bot token · Invite link with the needed permissions

Remove access

  • Server Settings → Integrations, or https://discord.com/settings/authorized-apps
  • In StreamHelm: disconnect the account (deletes the stored token).
