Anthropic (Claude)

Your own app: available

What StreamHelm uses it for

  • One of three AI frameworks the user can choose per job: the bot's replies, events and memory, Discord chatbot, clip titles / captions, clip watching (images), trend lookups (web search), the setup helper

Permissions requested

  • API key (optional admin key for spend reports)

Data

Only for the jobs the user assigns to Claude: text prompts and - only when switched on - clip frames. Claude does not receive audio. The key is stored encrypted on the user's PC.

How to connect

  • Your own developer app - Your own developer app - you create a free app on the platform and paste its keys into StreamHelm's encrypted Key Vault. Works today; the app walks you through it step by step.

Setup in short: Claude Console account with prepaid credits and an API key · Choose what it does on the AI Models page

Remove access

  • https://platform.claude.com/settings/keys
  • In StreamHelm: disconnect the account (deletes the stored token).
