StreamHelm is an all-in-one Windows control center for a Twitch channel: an AI chat co-host with memory, stream management, scene building, overlays, alerts, a Discord bot, and a clip studio that turns Twitch clips into Shorts, TikToks and Reels.

StreamHelm is a Windows desktop app, made by ThePepeSilviaShow. Its built-in AI co-host is called PepeBot - every streamer can rename it and give it their own picture. Everything runs on the streamer's own PC: logins and keys are encrypted with Windows data protection, viewer memory stays in local files, and nothing is sent to a StreamHelm server - there isn't one.

About

StreamHelm is a control center for streamers: one app that runs an AI co-host with a real memory, drives OBS, builds your scenes and overlays, handles alerts and channel points, runs a Discord bot, and turns your clips into Shorts, TikToks and Reels. It is built to save you time, make your stream feel like yours, and make your content stand out.

Why it exists

I love creating unique environments and spaces, and I love setting myself apart. A finely tuned, personal chatbot is a big part of that for me, and so are the unique features that make my stream feel like my stream.

I don't have a huge following, but I put a lot of time and energy into shaping the atmosphere for the people who are there. A goofy chatbot turned out to be something my regulars genuinely love - so I wanted to bring him into Discord too. Getting one bot to live in two places is what sent me down the path of building an app.

Features

🐸 PepeBot - the AI co-host

A chat bot with a personality and a long memory that talks with viewers, remembers them across streams and helps run the show.

🎛 Stream Manager

Run OBS from one screen: preview, scenes, sources, audio mixer, go live, stats, chat and quick actions - in panels you can arrange freely.

🖼 Scene Builder

A Canva-style editor for stream scenes - shapes, text, images, video, frames for webcams and game captures, widgets - published to OBS as one locked scene.

✨ Overlays & alerts

Browser-source overlays that update live: voice overlay, Now Playing, chat box, and an alert system with text-to-speech.

🎬 Clip Studio

Turn Twitch clips (or any video) into vertical shorts and post them to YouTube Shorts, TikTok, Instagram Reels and Facebook Reels.

🔗 Socials & link library

Connect YouTube, TikTok, Instagram and Facebook for posting, and keep every social link in one library used everywhere else.

🧠 AI frameworks: GPT, Claude, Gemini

Link OpenAI, Anthropic Claude and Google Gemini and choose which one - and which model - does each job, with cost estimates and balances per framework.

🎙 Voice Chat with PepeBot

A channel-point reward: PepeBot talks with the streamer out loud for a few minutes - he hears the mic and answers with his own voice.

🎬 Character scenes + cast overlay

Characters talk to each other out loud while a cast overlay lights up whoever is speaking.

🗡 Mantella bridge (Skyrim)

Skyrim NPCs (Mantella) run through StreamHelm: they know your stream, get captions, remember it, and chat can whisper to them.

🧙 Characters + Talk hotkey

Every character chat voices gets its own voice, bios and memory - and you can talk with any of them (or PepeBot) from a hotkey, mid-game.

🎙 Voice Lab

Design a brand-new voice from a description, or clone your own - for PepeBot or any character.

🎭 Speak as a Character

Viewers send a line for the character in your game; a hotkey draws one from a secret lottery and it's spoken in the character's voice, with a caption.

📈 Chat Pulse

An overlay of what chat keeps repeating - words, phrases and emotes with running tallies - plus chat votes and an AI choose-your-own-adventure.

🧩 Feature Builder

Make PepeBot do new things without code: pick when (command, keyword, event, reward, timer) and what (say, AI reply, alert, OBS, counter, Discord, TTS…).

🟣 Discord bot

PepeBot in your Discord: chat with memory, moderation, verification, AutoMod sync, stream alerts, events and a daily server "vibe" log.

☁ StreamHelm Cloud + SQLite storage

PepeBot on an always-on server (a $4-6 VPS or a Raspberry Pi) while your PC is off - one shared memory, taking turns so only one PepeBot answers.

🛡 Safety, privacy & backups

Word filters, panic mute, AI budget, backups, diagnostics without secrets, and "forget me" for viewers.

Connected services

StreamHelm connects to Twitch, Discord, Spotify, OBS and the AI providers the owner chooses (OpenAI, Anthropic Claude, Google Gemini), and - for the Clip Studio - YouTube, TikTok, Instagram and Facebook. Each service has its own page explaining exactly what is used and why.

YouTube (Google)

Upload the clips you choose as YouTube Shorts / videos · Show which channel is connected (name, handle, avatar)

TikTok

Send clips to the user's TikTok inbox as drafts, or post them directly · Show which account is connected

Instagram + Facebook (Meta)

Publish clips as Instagram Reels to the user's professional account · Publish the same clips as Reels to the user's own Facebook Page (optional, per post or automatically) · Show which Instagram account / Facebook Page is connected

Twitch

Read chat and events (EventSub) and post as the bot account · Channel points, polls, predictions, shoutouts, clips, stream info, moderation

Discord

Run PepeBot as a Discord bot (chat, moderation, alerts, events) · Voice overlay: who is speaking in the streamer's voice channel

Spotify

Now Playing overlay and !song · Song requests via channel points: search, queue, skip

OpenAI (GPT)

One of three AI frameworks the user can choose per job: the bot's replies and memory updates, clip titles / captions, clip watching and listening (optional), burned-in captions with word timings, trend lookups, the setup helper · Text-to-speech voices

Anthropic (Claude)

One of three AI frameworks the user can choose per job: the bot's replies, events and memory, Discord chatbot, clip titles / captions, clip watching (images), trend lookups (web search), the setup helper

Google Gemini

One of three AI frameworks the user can choose per job: replies, memory, clip titles / captions, clip watching and listening, trend lookups (Google Search grounding), the setup helper · Text-to-speech voices (30 voices)

OBS Studio

Scenes, sources, audio, streaming / recording, screenshots and the virtual camera via obs-websocket on the same PC

Sign-in with Google, TikTok and Meta

The app signs in to YouTube (Google), TikTok and Instagram / Facebook (Meta) only to upload videos the user chose, with text the user approved, to the user's own accounts, and to read the basic profile of the account being posted to. See the Privacy Policy and Terms of Service.

What's new

v4.0.0: Storage: PepeBot's memory can live in one SQLite database instead of thousands of JSON files - a switch on the new Cloud & Storage page with Test the switch, an automatic backup, a checked transfer, and the same switch back; older versions of every document are kept and every change is logged · StreamHelm Cloud: PepeBot on an always-on server - set it up for me (Hetzner, DigitalOcean or Vultr API token → server bought, installed, HTTPS, app + keys + memory sent), one install command for any server, or a Raspberry Pi at home · The PC and the server take turns: the server covers Twitch chat and the Discord bot while the PC is off (or keeps Discord all the time); memory syncs both ways; the server gets its own Twitch logins; updates itself when StreamHelm updates · Everything between PC and server is signed and encrypted with a key only those two have; keys on the server are encrypted at rest · This PC: choose the local server port and let other devices on your network reach it (two-PC setups, Mantella on a gaming PC) · Setup guides with Assisted / Manual tabs, a Documentation section on the Launchpad, and Cloud & Storage status on the Dashboard and Connections.
